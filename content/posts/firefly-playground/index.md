## 一份可以直接修改的排版样本

本页文字专为这个排版实验独立编写，三张图片是本地生成的原创几何插画。它们只承担观察布局的任务：第一组图在左侧，第二组图在右侧，第三组图在上方。后面还有合成动画、测试音和视频图案，可以检查不同资源的展示方式。

你可以直接修改这份 Markdown，把插画换成自己拥有使用权限的图片。每张图与相关段落组成一个块，块外仍然是普通正文。缩窄窗口或用手机打开，同一份内容会自动变成上图下文。以下说明讲的是编排规则，不承载其他文章的故事或段落。

## 实验一 · 左图与长段落

```firefly
type: composition
layout: image-left
media:
  type: image
  src: ./assets/lakeside.png
  alt: 三角形山峦、圆形太阳和弧形地面组成的绿色几何插画
  caption: 原创几何插画 A · 用于观察左侧环绕
content: |
  这一组用左侧插图测试连续段落的排列。图片由三角形、圆形和弧线组成，颜色与形状都只是观察材料。阅读时可以先看第一行文字的起点：在足够宽的窗口里，它应当位于图片右侧，并留出稳定的间距。图注在图片下面，说明这张图在本实验中的用途。

  接下来观察第二段与第一段之间的空隙。它们保持普通正文的段落关系，没有为了填满右侧空间而被拆成零散的小格子。增加几句话或删除一句话，下一段就会自然移动。作者不需要提前知道图片会有多高，也不用记录某一行应该在哪个词后面换行。这种可变长度的说明，适合用来检查浏览器是否仍然在排普通文字。

  **图片与这些段落共享一个明确的组合边界。** 把相关文字放在同一个声明里，是为了让作者知道环绕到哪里结束。图片并不会继续影响后面任意数量的正文，也没有“下三个段落属于这张图”这样的隐含约定。阅读顺序始终是插图及其说明，然后是当前这些段落；显示位置的变化不会改写源文件里的顺序。

  这里特意加入一段较长的原创说明，检查文字到达图片下沿之后的状态。预期结果是后续行重新使用完整宽度，而不是一直停留在右侧窄列。你可以拖动窗口边缘，观察这个转折点如何随着可用空间而改变；也可以放大文字，看看相同内容占据更多行以后，图片、图注和段落之间是否依然保持清楚的关系。实验不要求某一句话永远出现在同一个坐标，它关注的是内容能否在不同尺寸下继续连贯阅读。

  最后一段仍然属于左图这一组。较短的说明可能在图片旁边就结束，较长的说明则可以继续向下，两种情况都不需要改变声明结构。保存文件后，网站负责再次生成展示，作者只维护一份图片引用和一份正文。检查完这里，再看下面单独的一段：它已经离开组合边界，应当按照普通文章的行宽排列，而不是继承这一组的左侧插图。
```

这一段在组合块外。无论上面的图片有多高，后面的正文和标题都会从新的一行开始，不会继续绕着上一张图。

## 实验二 · 右图与阅读顺序

```firefly
type: composition
layout: image-right
media:
  type: image
  src: ./assets/bookshop.png
  alt: 不同高度的彩色矩形排列在水平分隔线上，右下方有绿色叶片
  caption: 原创几何插画 B · 用于观察右侧环绕
content: |
  第二组把插图放到右侧，使用同样的正文规则。图里的彩色矩形和水平分隔线，可以帮助观察图片边界与文字基线之间的关系。在宽屏上，第一段从左侧开始，右侧保留插图；在窄屏上，图片先出现，文字在它下面接着排列。作者不需要为这两种情况准备不同的内容。

  这张插图有自己的替代文本和图注。替代文本描述重要的图形信息，图注说明它为何出现在这里，两者承担不同的任务。给图片补充说明时，不必把正文整段重复进去，也不应该把文件名当作唯一描述。这个实验用一句形状描述和一句用途说明，让两种信息在实际页面上都能被单独检查。

  左右位置只是局部编排选择，不能改变段落原本的先后关系。把这一段再复制一份，或者在两段之间插入一句说明，都应当得到正常的连续正文。如果读者选择文字、打开链接或使用浏览器自己的查找功能，这些内容也应当继续作为文章的一部分存在，而不是等待某个独立组件加载后才临时出现。

  为了观察图片底部附近的变化，这一组也保留足够长的原创文字。请留意某一行从较窄的左侧区域过渡到完整行宽时，文字是否仍然顺着上一行阅读。浏览器可能因为字体、字号和窗口宽度不同，在不同位置发生这个过渡。只要段落次序、图片边界和组外正文都正确，就不需要为了某张截图而固定行数或插入多余换行。

  现在可以尝试只修改布局字段：把右图改成左图，保留图片与所有段落，再重新查看。变化应当集中在图片的位置以及附近几行文字的排列，正文内容本身不需要重写。继续增加说明时，后面的行会自然接在下面，而不会生成另一列独立滚动的文字。最后这个段落仍在组合内部；下一段普通正文则提供一个清楚的边界标记，帮助检查前面的插图是否已经结束影响。
```

这是第二组之后的普通正文。左右交替只改变图片的位置，不改变 Markdown 的顺序，也不会要求另一份“手机专用文章”。

## 实验三 · 图上文下

```firefly
type: composition
layout: image-top
media:
  type: image
  src: ./assets/harbor.png
  alt: 深蓝背景中排列着亮色矩形与三角形，下面有水平色带
  caption: 原创几何插画 C · 用于观察居中与上下排列
content: |
  第三组将图片放在上方居中，文字从下方开始。这种布局可以用来展示需要完整横向空间的插图，也方便比较图片与文章正文的宽度关系。

  调整窗口宽度后，图片应当保持自身比例并留在可用区域内。这里不安排文字同时出现在图片左右两侧；读者依次查看图片、图注和正文即可，不需要寻找另一条阅读路线。
```

## 把它换成自己的文章

一个图文组合只需要确定图片位置、图片地址和相关正文。例如：

````markdown
```firefly
type: composition
layout: image-left
media:
  type: image
  src: ./assets/lakeside.png
  alt: 绿色几何插图
  caption: 用于测试组合边界的原创插图
content: |
  这里写和图片放在一起的第一段正文。

  这里可以继续写第二段，支持 **强调** 和普通 Markdown 链接。
```

这里是组合之外的正文。
````

把 `image-left` 换成 `image-right` 或 `image-top`，就能切换另外两种排列。其余内容继续使用普通 Markdown。

分享这份试验册时，请把旁边的 `assets` 目录一起带走。其他 Markdown 查看器会把 Firefly 声明显示成代码块，块外正文仍然可以阅读。网站目前保留媒体原始大小，不会自动压图或转码；换成自己的照片前，先准备适合网页阅读的尺寸会更舒服。
