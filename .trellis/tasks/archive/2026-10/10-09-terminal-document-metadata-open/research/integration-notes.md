# Integration boundaries

The owner updated the metadata order before source implementation: standalone
date/bytes/license/Share and inline cat path followed by date/bytes/license.
The existing renderer exposes validated original source bytes; no schema or
provenance pipeline expansion is required.

Current site rendering distinguishes document-navigation from Experiment
navigation, but submit previously assigned either destination into the current
window. Document intent must open a separate tab and suppress successful
navigation output; Experiment launch retains its established path. Native inline
Open uses a target-blank anchor with opener isolation and capability-aware href.

The reviewer identified same-tab assumptions in three document navigator tests,
including Back/Forward, plus exact generated asset inventory assertions. Replace
those assumptions with popup-local navigation and retained source-session
evidence; retain precise route-owned asset assertions when standalone Share adds
its independent module.

Share is already a protected native keyboard target for the navigator. Its
independent startup must reveal both any hidden wrapper and the button, and CSS
must explicitly honor hidden state. Async clipboard completion needs lifecycle
invalidation across pagehide/pageshow so old pending callbacks cannot restore
feedback or release a newer request. Static metadata stays readable without JS.

Native window opening with a noopener feature can return null on success; that
return must not be treated as proof of blocking. A synchronous blank-tab handle,
opener retirement and validated local destination permit actual blocked/null
handling without replacing the source Terminal. Final browser and independent
review results will be recorded separately; these notes do not claim a pass.
